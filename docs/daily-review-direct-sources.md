# 데일리 리뷰 직접 공급원 연결 — 2026-10-16

## 변경 사항

- 미국 재무부 공식 XML에서 명목 파 수익률(1·1.5·2·3·4·6개월, 1·2·3·5·7·10·20·30년), 실질 파 수익률(5·7·10·20·30년)을 수집한다. `UST_*` / `UST_REAL_*` 별도 계열이며 FRED 원자료를 덮어쓰지 않는다. 공급원이 제공하지 않는 만기·날짜는 채우지 않는다.
- 기본 직전 연도부터 현재 연도까지 조회해 수정값도 재확인한다. 첫 저장은 기준선이며 뉴스처럼 과거를 신규 발표로 알리지 않는다. 이후 관측 추가·수정은 기존 경제지표 변경 로그에 기록한다.
- 시장 차트의 미국 1·2·10·30년은 재무부 저장 자료를 우선한다. 미수집 시 기존 KIS 또는 FRED로 계열 전체를 대체하고 실제 공급원을 표시한다. 경제지표 탭에서는 재무부와 FRED를 각각 선택해 비교할 수 있다.
- Yahoo 선물·달러지수에서 자정 일봉과 같은 날짜의 실시간 추가 행을 분리한다. 실시간 추가 행은 확정 일봉을 덮어쓸 수 없다. 현재 현지 날짜는 기존 공급원 세션 종료 + 30분 확인을 유지한다. 공식 거래소 정산가 수집이라고 표시하지 않는다.
- 상태는 관측일 기준이다. 최근 수집 실패는 기존 저장값과 함께 표시한다. 전일 미반영은 공표 대기·휴장 가능성을 명시하며 날짜 차이만으로 실패라고 단정하지 않는다. 주말은 제외하지만 시장별 공휴일 자동 판정은 하지 않는다. SOFR·DFF는 미국 다음 영업일 공표 한계를 안내한다.
- KIS 수집, BTC 09:10, FRED 경제지표 수집, 개인용 데이터 소유자 권한 검사는 유지한다.

## 한국시간 스케줄

| 작업 | 실행 시각 |
| --- | --- |
| 재무부 | 07:15, 08:15, 10:15 |
| Yahoo | 07:15, 08:15, 13:45 |
| 오피넷 | 07:15, 10:15, 14:15 |

추가 실행은 동일 키에 upsert하므로 날짜별 중복 행을 만들지 않는다. 매번 조회 구간의 수정값도 확인한다. 공표 전이면 성공해도 전일 값은 없을 수 있다. Mac이 실행 가능해야 launchd 작업이 작동한다.

## 확인할 제한

- 재무부 파 수익률은 공식 추정 수익률이며 거래된 채권의 마지막 체결가가 아니다.
- Yahoo의 현지 날짜 및 세션 메타데이터는 거래소 실제 세션과 다를 수 있다. 안전하게 확정 여부를 판단하므로 아침에는 하루 이전 값이 보일 수 있고, 오후 보충 수집으로 재확인한다. 전일 값이 아침에 반드시 필요하면 검증된 거래소 일봉/정산가 공급원이 추가로 필요하다.
- FRED의 SOFR·DFF·광의 달러지수·WTI 현물 등 원기관 공표 지연 자체는 이번 연결로 해소되지 않는다.
- 뉴스 선별 및 경제지표 AI 해석은 이번 변경 대상이 아니다.

## 검증

- XML 누락·음수 실질금리·미래 날짜·비정상 값, Yahoo 실시간 중복·미완성 일봉·서머타임 회귀 테스트 7건 통과.
- 수정 TypeScript 파일 ESLint 및 Next.js webpack 프로덕션 빌드 통과.
- 오피넷 3종, Yahoo 6종 실제 수집/저장 최신 관측일 2026-10-15 확인.
- launchd 3개 등록 및 plist 문법 확인 완료.
- 재무부 19종 총 8,462개 관측 저장 완료. 전 계열 최신 2026-10-15, 최초 저장 변경 알림 0건. 시장 API 미국 1·2·10·30년이 재무부 2026-10-15 값으로 응답함을 확인.
- 관측일 상태 분기 7건 확인(오류·미수신·주말·BTC 연속 거래). 경제지표 API 200, 모바일 페이지 200, 비로그인 개인용 Yahoo API 401 확인.
- 이번 화면/API 변경은 로컬 구현 및 빌드 검증이며 공개 사이트 프론트엔드 배포는 수행하지 않았다. DB 수집과 launchd 스케줄은 실제 반영됐다.
