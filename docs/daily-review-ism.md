## ISM 수집 방법과 제한

- ISM 홈페이지에 대한 Python HTTP 요청은 404 또는 로그인 리다이렉트가 발생했다. 이를 우회하지 않고 ISM이 직접 발행한 공개 PR Newswire 보도자료를 사용한다.
- [발행기관 목록](https://www.prnewswire.com/news/institute-for-supply-management/)에서 각 부문의 최신 보고서 링크를 찾는다. 고정된 월별 주소나 검색 요약의 숫자를 사용하지 않는다.
- 발행기관, 보고서 제목의 부문·연월·PMI 숫자, 최근 12개월 표의 부문과 수치를 확인한다. 12개월 연속성·0~100 범위·중복·최신 월과 제목 수치 일치·미래/오래된 보고서를 검증한다. 최신 보고서 검증 실패 시 과거 보고서를 몰래 대체하지 않는다.
- DB에는 월별 수치와 공급원 링크만 저장한다. HTML/원문 전체는 저장하지 않는다. 최초 12개월 이력에서 시작하고 이후 월별 이력을 계속 쌓는다. 공급원이 최근 이력을 수정하면 기존 변경 기록 방식으로 감지한다.
- 표에서 행을 누르면 차트와 공식 발표 링크를 표시한다. PMI는 월간 수익률처럼 계산하지 않고 전월 대비 pt 변화 및 50 기준 확장/위축을 안내한다.
- 발표 원시각 DB 저장은 별도 작업이며 기존 표의 신규 감지순 정렬 원칙을 유지한다. 공개 홈페이지 확인 가능성과 대량 이력 API 제공은 다르므로, 이 수집은 공개 보고서 형식 변경 시 실패할 수 있다.
