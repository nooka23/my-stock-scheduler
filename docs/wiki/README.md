# 개인 종목 위키 작업 안내

이 폴더는 기존 `my-stock-scheduler` 사이트에 추가할 개인 종목 위키의 계획과 진행 기록을 관리한다.

## 다음 작업자가 읽을 순서

1. [진행 기록과 인계 — progress.md](progress.md): 현재 상태, 사용자 요청 범위, 완료한 일, 다음 작업, 검증 결과
2. [구현 계획 — plan.md](plan.md): 요구사항, 디자인 기준, 기술 설계, 단계별 완료 조건
3. [디자인 참고 자료 — references/README.md](references/README.md): PC·모바일 이미지와 웹 아카이브 보존 위치
4. [HTML·CSS 분석 — references/namuwiki-source-analysis.md](references/namuwiki-source-analysis.md): 원본 스타일 근거, 수정한 수치, 동작 검증이 남은 항목
5. [운영 적용 안내 — operations.md](operations.md): DB 마이그레이션·소유자 UUID 등록·실계정 확인 순서

현재 진행 상태의 기준 문서는 `progress.md`다. 요구사항과 설계의 기준 문서는 `plan.md`다. 상태를 여러 문서에 서로 다르게 기록하지 않는다.

## 기록 원칙

- 위키 관련 작업을 시작할 때 진행 기록과 최신 사용자 요청을 함께 확인한다.
- 위키 관련 작업을 마칠 때 `progress.md`의 현재 상태·다음 작업·검증 결과를 갱신하고 작업 로그를 추가한다.
- 사용자 결정이나 설계가 바뀌면 `plan.md`도 수정하고 변경 이유를 작업 로그에 남긴다.
- 사용자 확정 사항, AI의 추천안, 확인한 사실, 미검증 사항을 구분한다.
- 계획 수립이나 문서 작성은 기능 구현 완료로 기록하지 않는다.
- 비밀키, 비밀번호, 인증 토큰, 개인 매매 데이터는 기록하지 않는다.
- 이 문서들은 구현이나 배포를 자동으로 허가하는 지시가 아니다. 최신 사용자 요청이 작업 범위를 결정한다.

문서는 저장소 안에서 이동해도 참조할 수 있도록 상대 경로를 사용한다. 실제 참고 화면은 `public/`이 아닌 이 문서 폴더에 보관한다.
