## 해석할 때 주의할 점

- 모바일 이미지는 폭 163px로 축소되어 폰트 크기·터치 영역을 정밀 측정할 수 없다. 구현 초기값과 실제 S25 검증이 필요하다.
- PC 이미지 픽셀 수와 브라우저 CSS 픽셀의 대응을 검증 없이 확정하지 않는다.
- PC PNG에는 `LED MONITOR` 색상 프로필이 포함되어 있다. 원시 RGB 값과 sRGB로 해석한 색상을 혼동하지 않는다. 저장한 파일은 색 변환하지 않은 원본이다.
- 글꼴 선언·접기 구조는 저장본으로 보완했다. 실제 선택된 글꼴, 각주 팝업 작동, 편집 화면은 미확인이다.
- 갈색 배우 프로필 표는 해당 문서의 내용이며 기업 위키의 필수 양식으로 만들지 않는다.
- 광고·큰 빈 공간·토론·실시간 검색어는 첫 위키의 재현 범위에서 제외한다.

측정값과 구현 제안은 [계획서 3절](../plan.md)에 정리되어 있다.

- 로컬 보존: `source/namuwiki-sadie-sink.webarchive`
- 파일 크기: 5,079,394 bytes
- SHA-256: `0846f81091585cf752bcb04b5590e5850a1c29c37b038884d9479de145eec1f6`

- 주 문서가 링크한 외부 CSS 3개 모두 보존본 안에서 확인했다. 모바일 미디어 쿼리도 포함되어 있다.
- 원본과 복사본 체크섬·CSS 포함 여부·CSS 구문 분석을 검증했다. 원본 스크립트를 실행하거나 외부 자원을 요청하지 않았다.

원본 저장본에는 페이지 상태와 제3자 자원 정보가 포함되므로 [.gitignore](.gitignore)에서 `source/`를 제외했다. 로컬 원본은 지우지 않았다. 다른 컴퓨터의 AI도 보고서·선별 근거로 판단을 이어갈 수 있다. 전체 원본 재분석이 필요한 경우에만 해당 보존 파일을 전달한다.

### 남은 확인

- 실제 S25 브라우저·CSS viewport·글자 확대·선택된 한글 글꼴·줄바꿈.
- 목차 조작·절 접기·각주 팝업·분류 펼치기의 실제 동작.
- 편집 화면과 키보드·저장 흐름은 자체 구현 후 확인.

추가 자료는 위 항목을 확인하는 데 필요할 때만 요청한다. PC 저장본의 반응형 규칙을 확인한 것과 실제 S25 동작 확인을 구분한다. 광고·추적·사이트 스크립트를 앱에 통째로 이식하지 않는다.

### 자료 전달 방식의 기록

이전 안내는 Safari에서 **파일 → 별도 저장 → 포맷: 웹 아카이브**였다. [Apple 공식 안내](https://support.apple.com/ko-kr/guide/safari/ibrw1089/mac) 사용자는 그 방식의 파일을 제공했다. HTML과 자원 폴더 ZIP도 분석 가능하지만 지금 추가 전달을 요구하는 것은 아니다. 나무마크 본문 소스만으로는 사이트 CSS를 확인할 수 없다.
