# 데일리 리뷰 표 UI — 2026-10-16

## 구현

- 시장 뉴스 이후의 시장지표를 표로 표시한다. 현재값·단위·관측일과 1일/1주/1달 변화를 함께 제공한다. 금리/환율/원자재 탭은 같은 표의 분류 행으로 전환했다.
- 차트는 기본적으로 닫혀 있으며 행 또는 키보드로 접근 가능한 지표 버튼을 눌러 그 행 아래에서 펼치고 닫는다. 시장 차트의 1M/3M/1Y 선택, 공급원·관측일·지연 안내를 유지한다.
- 1일은 직전 유효 관측 대비, 1주는 표시된 최신 관측일의 7일 전, 1달은 1개월 전(월말 보정) 대비다. 기준일이 휴장이면 이전 관측을 사용한다. 7일을 넘는 기준 관측 공백은 수익률을 생성하지 않는다. 기준값 0/음수나 부족한 이력은 `—`다. 금리는 채권 가격 수익률 대신 수익률 수준의 bp 변화다.
- 경제지표는 `view=indicators`에서 일간 금융자료/금리/시장보조를 제외한 29종을 조회한다. 기본 전체 분류에서 최근 값·이전 값·관측 기간·신규 감지 시각을 표로 비교하며 분류 필터와 행별 차트를 제공한다. 기존 전체 경제지표 API와 저장 자료는 유지한다.
- 실제 원기관 발표 시각은 현재 DB에 없다. 최신 관측값의 `economic_changes.kind=new` 최초 감지 시각을 정렬 기준으로 사용한다. 수정 감지나 단순 수집 점검 시각을 새 발표 시각으로 사용하지 않는다. 초기 기준선 저장에는 감지 기록이 없으므로 관측 기간순으로 보완한다. 이 제한을 표 위에 명시한다.
- 과거 리뷰의 정렬에 이후 날짜의 신규 감지 기록을 쓰지 않는다. 차트 값은 기존 정책대로 현재 저장된 수정값이다.
