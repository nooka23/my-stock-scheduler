# 데일리 리뷰 화면 시안

## 범위

- 경로: `/daily-review` (독립 일반 메뉴 → 데일리 리뷰). 관리자 권한이나 로그인 없이 접근할 수 있다.
- 모바일 전용 미리보기: `/daily-review/mobile`. 데스크톱에서도 최대 430px 너비로 모바일 레이아웃을 비교할 수 있으며, 기본 화면도 화면 너비에 따라 반응형으로 표시한다.
- 이전 `/admin/MH/daily-review` 주소는 `/daily-review`로 리디렉션한다.
- 사용자의 요청에 따라 데이터 확보 전에 리뷰 흐름을 검토하는 화면을 구현했다.
- 뉴스·경제지표·AI 해석은 합성 예시다. 2026-10-14부터 검증된 KIS 8종 가격 차트는 실제 DB 일봉으로 연결했다. 미연결 자산은 빈 상태를 표시한다.
- 리뷰 날짜는 한국시간 오늘을 기본으로 선택한다. 가격은 리뷰 전일 이하의 관측값만 조회한다. 뉴스·경제지표 예시는 날짜와 무관한 가상 내용이다.

## 동작

1. 시장 뉴스: 중요도 순의 사건 목록, 분류 필터, 읽음, 안 읽은 사건만 보기, 선별 이유와 출처 구성 펼치기. 건수 제한 없음.
2. 경제지표: 발표가 있는 날 CPI 예시 카드(MoM/YoY, 계절조정 구분, 추이, AI 해석), 발표 없는 날의 빈 상태.
3. 매크로: 금리/환율/원자재 분류와 개별 자산 선택.
4. 위험 심리: VIX/금/BTC 선택.
5. 지수: S&P 500/나스닥/다우/러셀/SOX 선택.
6. 대형주 검토: 일반 이용자가 접근하는 기존 `/chart`로 연결. 새로운 종목 검토 페이지는 만들지 않음.
7. 리뷰 메모: 날짜별 메모와 확인 표시를 명시적인 저장 버튼으로 localStorage에 보관. 기기 간 동기화와 계정별 분리는 미구현이며 화면에 브라우저 저장임을 안내한다.

상단에서 경제지표의 새 발표 / 발표 없음 예시를 전환한다. 가격 영역은 실제 관측일, 조회 실패, 데이터 없음, 미연결을 표시한다.

기존 `IndexLineChart`를 재사용하고 선택적인 `pricePrecision`을 추가했다. 기본 차트 사용처의 설정은 그대로 유지하며 새 리뷰에서는 환율·금리 등의 소수점 정밀도를 지정한다. 금리 변화는 bp, 가격 변화는 %로 구분한다.

전역 상단 메뉴는 일반 서비스, 관리자 드롭다운, 계정 메뉴로 정리했다. 모바일에서는 스케줄러·데일리 리뷰·기업 분석과 전체 메뉴 버튼을 표시한다. 전체 메뉴는 모달로 열리며 Escape와 닫기 버튼으로 닫힌다. 관리자 및 개인 위키 메뉴의 기존 권한 조건은 유지한다. 리뷰의 모바일 섹션 이동과 자산 선택은 가로 스크롤 대신 줄바꿈하는 격자로 구성했다.

## 데이터 연결 전 결정할 것

- 자산별 정확한 상품, 공급원, 일봉 시간대, 최신값 도착 시각.
- 현물/선물 구분, 선물 계약 교체, 확정 일봉과 리뷰 시점 스냅샷 구분.
- 발표 관측 기간, 발표 시각, 수집 시각, 수정 이력과 예상치 출처.
- 뉴스 중요도 기준, 사건 묶음, 원문 출처, 수집 실패 표시.
- 실제 데이터 및 개인 메모를 연결하기 전 공개 시황과 사용자별 저장 범위. 현재 일반 페이지에는 공개 가능한 합성 예시만 포함한다.

뉴스 수집·선별·저장 원칙은 [데일리 리뷰 뉴스 수집 계획](./daily-review-news-plan.md)을 따른다. 중요도 기준을 통과한 사건과 근거 기사 참조만 날짜별로 보존하고, 전체 원문은 영구 저장하지 않는 방향을 사용자가 승인했다. 실제 RSS/AI/DB 연결은 별도 구현 단계에 있다.

## 검증

- 로컬 브라우저에서 뉴스 필터, 발표 없음, 가격 지연, 환율 자산 전환 확인.
- 메모와 확인 표시 저장 후 새로고침 복원 확인. 검증용 메모 정리.
- 390×844 모바일 화면에서 뉴스와 CPI 레이아웃, 차트, 섹션 이동 확인.
- 비로그인 상태에서 새 일반 경로와 모바일 미리보기 접근 확인. 390px 화면의 문서 너비가 390px임을 확인했고 전체 메뉴 열기·Escape 닫기·초점 복귀를 확인했다.
- 이전 MH 주소에서 일반 주소로 실제 이동하는 것을 확인했다. 변경한 메뉴·레이아웃·리뷰 페이지에 대한 ESLint 검사는 통과했다.
- 프로덕션 빌드 성공. 저장소 설정상 빌드가 타입 검증을 생략하므로 별도 `tsc --noEmit`도 수행했고 기존 파일의 오류를 확인했다.
- 전체 `npm run lint`는 메모리 부족으로 종료. `eslint src`는 기존 코드 오류를 보고했다. 새 페이지 및 수정 파일은 별도 범위 검사로 검증한다.

## 2026-10-14 KIS 연결

- 대상: S&P 500, 나스닥, 다우, SOX, VIX, 미국 10년물, USD/KRW, USD/JPY.
- 기존 `collect_global_market_data.py`를 재사용하고 검증된 8종으로 수집 범위를 제한했다. 기본 종료일은 한국시간 전일이며 유효하지 않은 종가는 해당 자산 실패로 처리한다.
- 2026-10-13 종료일로 380일 범위를 조회하여 8/8 성공, 2,000행을 기존 `market_data.global_daily_prices`에 upsert했다. 공급원이 반환한 이력 길이는 자산마다 다르며 완전한 380일 이력을 보장하지 않는다.
- `/api/daily-review/market`은 자산 allowlist, 날짜 검증, 전일 상한, KIS 출처 필터를 적용한다. 원본 payload·인증키는 반환하지 않는다. 과거 리뷰는 현재 DB의 해당 관측일까지의 이력이며 당시 저장본을 재현하는 스냅샷 기능은 아니다.
- 기존 `run_us_equity_daily_local.sh` 마지막에 45일 갱신 단계를 추가했다. 새 예약 작업은 등록하지 않았다. 앞선 작업 실패 시 이 단계까지 도달하지 않는 기존 fail-fast 구조는 유지된다.
- API 실조회로 8종 최신일 2026-10-13을 확인했다. 미지원 자산·잘못된 날짜·미래 날짜 400 응답과 과거 날짜 상한 검증을 통과했다. 모바일 미리보기에서 미국 10년물 5.21%, 직전 관측 대비 -3.00bp 및 차트 표시를 확인했다.
- 관련 ESLint 통과. 프로덕션 빌드 성공(기존 설정은 타입 검증 생략). 별도 TypeScript 검사에서 리뷰 관련 오류는 없으며 기존 다른 파일의 오류가 남아 있다.

### 2026-10-14 추가 환율·금리 수집

- `daily_review_kis_instruments.py --apply`로 검증된 신규 직접수집 15종과 계산환율 1종을 등록했다. 재실행은 internal_code 기준 upsert이며 인증정보를 기록하지 않는다.
- 신규 환율: GBP/USD, EUR/USD, USD/CNY, JPY/KRW, 계산 CNY/KRW. JPY/KRW DB는 원/1엔을 유지하고 API 표시만 원/100엔으로 환산한다. CNY/KRW는 같은 관측일의 USD/KRW ÷ USD/CNY이며 시각별 고시 차이가 있을 수 있다. 계산 OHLC를 임의로 만들지 않고 종가만 저장한다.
- 신규 금리: 미국 1년·30년·연방기금금리·재할인율·우대대출금리, 한국 국고채 1·3·5·10·20·30년. 기존 미국 10년물 포함 국채 수익률과 정책·대출금리를 이름/설명으로 구분한다.
- 380일 요청: 직접수집 23/23 성공, 5,744행 및 계산환율 197행, 총 5,941행 upsert 성공. 이는 이번 실행 처리량이며 순증 행 수가 아니다. 공급원이 반환한 범위만 저장했다.
- 직접수집 신규 항목의 마지막 관측일은 대부분 2026-10-13, 미국 연방기금·재할인·우대대출금리는 2026-10-12이다. 관측일을 그대로 표시한다.
- 추가 항목은 기존 글로벌 수집 실행에 포함된다. 관련 ESLint 및 프로덕션 빌드 성공. API 실조회로 신규 항목과 엔화 환산·교차환율 계산을 확인했다.

### 2026-10-14 실제 뉴스 연결

뉴스 예시는 제거하고 `/api/daily-review/news`에서 날짜별 수집 실행과 ChatGPT 직접 선별 사건을 표시한다. 수집 실패·부분 수집·검토 대기·검토 완료0건을 구분하며, 근거 출처 링크·발행 시각·불확실성 설명을 제공한다. 이번 저장 결과는 37개 사건이고 출력 개수 제한은 없다. 뉴스 workflow와 현행 상태는 `daily-review-news-workflow.md`에 기록했다.

### 2026-10-14 BTC 개인용 연결 및 공급원 조사

Coinbase BTC/USD 완료 일봉 380행을 저장하고 기존 가격 패널에 연결했다. 데이터 이용 약관상 공개 표시 동의가 필요하므로 BTC API는 소유자 로그인으로 제한한다. UTC 봉은 한국시간 09시 종료하며 launchd는 매일 09:10 갱신한다. 공개용 BTC 및 금·구리·DXY·러셀 2000 공급원 결정은 아직 완료하지 않았다. 가격, 권한, 확인된 범위와 검증 결과는 [공급원 결정 기록](./daily-review-market-provider-decision.md)에 정리했다.

### 2026-10-14 Yahoo 개인용 데이터 저장

사용자 승인으로 금 선물 GC=F, 구리 선물 HG=F, DXY DX-Y.NYB, 러셀 2000 ^RUT 일봉을 DB에 저장하고 차트 API에 연결했다. 네 종 262행씩 총 1,048행이며 최신 관측일은 2026-10-13이다. 반복 upsert로 중복 없이 유지되는 것을 확인했다. 금의 기존 현물 표시는 금 선물로 수정했다. 매일 07:10 launchd 수집을 등록했으며 공급원 거래소 세션이 종료된 봉만 허용한다. 데이터 조회는 소유자만 허용하고 공개용 공급원 결정은 여전히 미완료다. 검증 결과와 운영 한계는 위 공급원 기록의 최신 구현 항목을 따른다.

### 2026-10-14 갱신 시간 통일 및 원유 세 종

사용자 요청으로 BTC 외 리뷰 데이터 갱신 시작을 07:15로 변경했다. FRED·Yahoo 예약을 수정하고 KIS 시장 수집을 미국 주식 파이프라인에서 분리해 07:15 별도 등록했다. BTC는 09:10을 유지한다. 오피넷 두바이 현물·NYMEX WTI 선물·ICE 브렌트 선물 일별 CSV를 실제 조회·저장하여 원유 세 종을 연결했다. 초기 총 793행이며 Yahoo 원유는 별도 출처로 유지한다. 상세 검증 및 운영 한계는 공급원 기록의 최신 결정 항목에 기재했다.

### 2026-10-14 미국 2년물 차트 연결

사용자가 요청한 미국 2년물만 추가 연결했다. 기존 FRED DGS2 economic_observations를 시장 API에서 직접 조회하므로 별도 수집기·중복 DB·예약은 추가하지 않았다. 화면 출처는 FRED · DGS2, 값은 수익률 %이며 기존 금리 패널의 변화량 bp 표기를 유지한다. 리뷰 전일 이하 관측값만 표시한다. 10월 14일 API는 254개 관측, 마지막 관측 10월 9일 4.80%를 반환했다. 9월 1일 과거 조회에서는 8월 31일 이하만 반환하는 것을 확인했다. 관련 ESLint와 프로덕션 빌드 성공. 브라우저 시각 검증은 수행하지 않았다.
